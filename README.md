# Maxwell Relations (Thermodynamics & Statistical Physics)

A clean Markdown and LaTeX documentation of the primary **Maxwell Relations** and their associated fundamental thermodynamic potentials.

This resource was created to address the lack of high-resolution, properly formatted PDF reference sheets for Statistical Physics coursework.

---

## 📄 Contents

The repository provides structured reference tables featuring:
- Fundamental functions ($U, H, F, G$, etc.)
- Variables to relate
- Mathematical expressions for the Maxwell relations

---

## 🛠️ Available Formats

- `Maxwell-Relations.md`: Source file formatted in Markdown with MathJax/KaTeX rendering for seamless previews in GitHub, Obsidian, or VS Code.
- `Maxwell-Relations.tex`: LaTeX source code for clean, vector-quality PDF compilation.

---

## 🚀 Usage

To compile the PDF directly from the `.tex` source file:

```bash
pdflatex MaxwellRelations.tex
